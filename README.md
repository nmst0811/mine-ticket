# Mine-Ticket
**リンク(デモサイト): https://mine-ticket-demo.vercel.app**

「Mine-Ticket」は、ファンメイド・無料イベントに特化した「手軽さ」と「気軽さ」を追求したチケット管理プラットフォームです。

## プロジェクト概要
- **コンセプト**: 「もっと気軽に、手軽に。」
- **ターゲット**:
  - **主催者**: 個人活動者、ファンコミュニティ、学生団体
  - **来場者**: そのファンや友人

-----

## 主な機能
Next.js、TypeScript、Prismaを使用した、申込みから入場までを一貫して行える無料サービス。
- イベント作成・管理
- チケット発行
- QRコード生成
- 入場管理（QRスキャン）
